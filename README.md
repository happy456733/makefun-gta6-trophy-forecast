Forecasts every Grand Theft Auto VI PlayStation 5 trophy's Exophase earn rate at 2026-11-26T00:00:00Z: a logit-scale trend extrapolation over each trophy's read history, with a spread that widens with the horizon and with Exophase's refresh jumps, so a forecast is not caught out by the first refresh it has not seen.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
